Dataset files

Plain CSV, UTF-8, one file per entity. No API key, no sign-up.

routes.csv
2,925 rows
One row per origin→destination route: bus count, operators, first/last departure, via stoppages.
Download routes.csv ↓
buses.csv
4,728 rows
One row per listed bus service: operator, type, depot, origin, destination, times, fare.
Download buses.csv ↓
stoppages.csv
61,126 rows
Ordered stoppage sequence for every listed service — the intermediate stops between origin and destination.
Download stoppages.csv ↓
stops.csv
2,740 rows
Canonical stop list with the routes and services that call at each stop.
Download stops.csv ↓

Quick start

Everything is plain CSV — pandas, R, or a spreadsheet all work.

# python
import pandas as pd
routes = pd.read_csv("https://raw.githubusercontent.com/murmusuvash2-wq/busjatri-open-data/main/data/routes.csv")

# busiest routes out of Kolkata
print(routes[routes.origin == "Kolkata"].nlargest(10, "bus_count")[["destination", "bus_count"]])
